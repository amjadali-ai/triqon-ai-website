# TRIQON AI — React + Vite + TypeScript Website

Production-ready React (Vite + TypeScript + Tailwind CSS + Framer Motion + Lucide) website for **TRIQON AI** (*Intelligence. Innovation. Impact.*).

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Push to GitHub & Deploy on Vercel

```bash
git init
git add .
git commit -m "Initial TRIQON AI React website"
git branch -M main
git remote add origin https://github.com/amjadali-ai/triqon-ai-website.git
git push -u origin main
```

Then import `amjadali-ai/triqon-ai-website` in [Vercel](https://vercel.com/new) (Framework Preset: **Vite**) and click **Deploy**.
